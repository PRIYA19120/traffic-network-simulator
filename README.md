# Traffic Network Simulator 🚦

**TrafficFlow – Smart Traffic Management and Simulation System**

## 📌 About the Project

Traffic Network Simulator is a web-based application designed to simulate traffic movement and demonstrate smart traffic management at a road intersection.

It provides a visual dashboard to monitor vehicles, traffic signals, road congestion, weather conditions, and emergency situations.

## ✨ Features

- **Live Traffic Simulation:** Visualizes vehicle movement at a road intersection.
- **Smart Traffic Signals:** Automatically changes traffic signal states.
- **Traffic Density Monitoring:** Displays traffic density for North, South, East, and West roads.
- **Emergency Vehicle Priority:** Provides signal priority for emergency situations.
- **Accident Detection:** Simulates accident alerts and monitors affected roads.
- **Live Weather Updates:** Fetches current weather information for a selected city.
- **Traffic Analytics:** Displays traffic data through a dynamic graph.
- **Vehicle Management:** Tracks moving and stopped vehicles.
- **Congestion Monitoring:** Identifies smooth, moderate, and heavy traffic conditions.

## 🛠️ Technologies Used

- Open-Meteo Weather API

## 🚀 How to Run the Project

1. Clone the repository:

```bash
git clone https://github.com/PRIYA19120/traffic-network-simulator.git
```

2. Open the project folder in VS Code.

3. Open `index.html` in your browser or run it using the VS Code Live Server extension.

4. Click **Start Simulation** to begin the traffic simulation.

5. Explore the different dashboard features.

**Note:** An internet connection is required for live weather updates.

## 🎯 Project Objective

The main objective of this project is to demonstrate how smart traffic management concepts can help monitor traffic conditions, manage vehicle movement, identify congestion, and prioritize emergency vehicles.
